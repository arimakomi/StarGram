۲۱. امنیت و حریم خصوصی

  • از رمز قوی و متفاوت برای حساب مدیر و حساب پایگاه داده استفاده کنید.
  • برای دامنه عمومی HTTPS را اجباری کنید و دسترسی مستقیم به فایل‌های سرور را ببندید.
  • مقادیر .env، رمزها و کلید Gemini را در مخزن GitHub قرار ندهید.
  • پوشه‌های داده و backup را فقط برای کاربر/سرویس لازم قابل خواندن کنید.
  • محدودیت دسترسی پنل مدیر را رعایت و نرم‌افزار سیستم‌عامل را به‌روز نگه دارید.
پیام‌های StarGram در قالب فعلی رمزگذاری سرتاسری (E2EE) نشده‌اند؛ متن قابل‌خواندن در داده همگام‌شده ذخیره می‌شود. این سرویس را معادل پیام‌رسان با E2EE فرض نکنید.

رمز عبور حساب با scrypt هش می‌شود و token نشست به شکل هش در سرور نگهداری می‌شود؛ با این حال، این پروژه را بدون ارزیابی مستقل امنیتی تلقی کنید. استفاده از Gemini اختیاری است و محتوایی که برای دستیار می‌فرستید به ارائه‌دهنده یا proxy پیکربندی‌شده ارسال می‌شود.

۲۲. رفع اشکال

npm run build خطای TypeScript می‌دهد

از پوشه اصلی پروژه اجرا کنید. مطمئن شوید checkout کامل است و فایل‌ها روی لینوکس با حروف بزرگ/کوچک درست قرار دارند. روی نسخه سرور git status و حضور فایل‌های مورد اشاره در خطا را بررسی کنید؛ سپس از شاخه معتبر پروژه npm ci و npm run build را اجرا کنید.

fatal: not a git repository هنگام آپدیت

نسخه فعلی فرمان sudo stargram update لازم نیست پوشه نصب Git repository باشد و آرشیو شاخه main را مستقیم دریافت می‌کند. اطمینان حاصل کنید که فرمان نصب‌شده در /usr/local/bin/stargram از همان نسخه جدید است؛ در صورت خطا log را با sudo stargram logs ببینید.

سایت باز نمی‌شود یا سرویس خاموش است
sudo stargram status
sudo stargram logs
sudo stargram health
sudo ss -ltnp

پورت تنظیم‌شده در .env، firewall، reverse proxy و وضعیت systemd را بررسی کنید. اگر systemd موجود نیست، از پوشه پروژه npm start را با مدیر فرایند اجرا کنید.

صفحه باز می‌شود اما ورود یا پیام‌رسانی کار نمی‌کند

بخش /api را در proxy بررسی کنید، مطمئن شوید proxy درخواست‌ها و WebSocketهای لازم را به پورت StarGram می‌فرستد و سرور از مرورگر قابل دسترسی است. Console مرورگر و log سرور را هم بررسی کنید.

برنامه به‌جای SQL از JSON استفاده می‌کند

DB_TYPE، میزبان، پورت، نام دیتابیس، کاربر و سطح دسترسی را در .env بررسی کنید. وضعیت موتور را از sudo stargram status یا پنل مدیریت بخوانید. پاسخ HTTP سالم به‌تنهایی سلامت اتصال SQL را ثابت نمی‌کند.

آپلود عکس/صدا یا ضبط میکروفون ناموفق است

HTTPS، اندازه مجاز درخواست در Nginx/Caddy، فضای دیسک، مجوز میکروفون مرورگر و دسترسی کاربر سرویس به فایل‌ها را بررسی کنید. پس از تغییر محدودیت proxy، سرویس را reload کنید.

دکمه نصب PWA نمایش داده نمی‌شود

HTTPS، مرورگر پشتیبانی‌شده، نصب‌نشدن قبلی سایت، بارگذاری manifest/service worker و گزینه Add to Home Screen در منوی خود مرورگر را بررسی کنید. اعلان مرورگر به‌تنهایی باعث نصب PWA نمی‌شود.

اعلان مرورگر یا صدا نمی‌آید

مجوز اعلان سایت و سیستم‌عامل، وضعیت mute گفتگو، گزینه صدای اعلان، فعال‌بودن تب/مرورگر و تنظیمات Do Not Disturb را بررسی کنید. بعضی مرورگرها تا تعامل کاربر اجازه پخش صدا نمی‌دهند.

۲۳. پرسش‌های رایج

آیا GitHub Pages خود پیام‌رسان را اجرا می‌کند؟

خیر. Pages این سایت معرفی و مستندات را میزبانی می‌کند. برنامه نیازمند Node.js و API روی سرور شماست.

آیا برای استفاده پایگاه داده SQL اجباری است؟

خیر، حالت JSON محلی برای نصب ساده وجود دارد. PostgreSQL و MySQL/MariaDB هم پشتیبانی می‌شوند.

آیا برنامه رایگان و متن‌باز است؟

کد با مجوز MIT منتشر شده است. هزینه VPS، دامنه و سرویس‌های جانبی را میزبان/مدیر سرور پرداخت می‌کند.

آیا اپ Android یا iOS جداگانه وجود دارد؟

نسخه این مخزن وب است و می‌تواند به صورت PWA به صفحه اصلی افزوده شود؛ اپ بومی جداگانه در این مخزن ارائه نشده است.

برای درخواست قابلیت یا گزارش خطا کجا بروم؟

نسخه، سیستم‌عامل، مراحل بازتولید و متن کامل خطا را بدون رمز، token یا داده خصوصی در GitHub Issues ثبت کنید.

برای بررسی کد، تاریخچه و انتشارهای پروژه به مخزن StarGram در GitHub بروید.
