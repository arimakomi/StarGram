StarGram چیست؟

StarGram پیام‌رسان وب و خودمیزبان برای گفتگوهای خصوصی، گروه‌ها و کانال‌هاست. مدیر آن را روی سرور لینوکس نصب می‌کند و کاربران با مرورگر به همان سرور وصل می‌شوند.

این سایت GitHub Pages معرفی و مستندات را میزبانی می‌کند؛ خود پیام‌رسان به Node.js و API روی سرور شما نیاز دارد. Pages جایگزین سرور برنامه نیست.
