راهنمای پنل مدیریت

پنل مدیریت ارشد تنظیمات و رسیدگی‌های سراسری StarGram را در هفت بخش جدا نگه می‌دارد: تنظیمات سیستم، برند و لوگو، توکن‌های API، گزارش‌ها، کاربران، گروه‌ها و کانال‌ها، و پایگاه‌داده. گزینه‌های نمایان به نقش حساب شما وابسته‌اند.

پنل وب با ابزار مدیریت سرور فرق دارد. برای وضعیت سرویس، گزارش‌های ترمینال، backup کامل و به‌روزرسانی از دستور stargram استفاده کنید.

باز کردن پنل

  1. با حساب دارای نقش مدیر وارد پیام‌رسان شوید.
  2. منوی کناری را باز کنید و گزینه پنل مدیریت را بزنید.
  3. از نوار افقی بالای پنل، بخش موردنظر را انتخاب کنید.

در نمایشگر کوچک، نوار بخش‌ها را با لمس یا کشیدن پیمایش کنید. روی رایانه می‌توانید از اسکرول‌بار، ترک‌پد یا کلیدهای جهت‌دار پس از فوکوس روی نوار استفاده کنید.

تنظیمات کلان سیستم

  • ایجاد گروه را برای کاربران روشن یا خاموش کنید.
  • ایجاد کانال را برای کاربران روشن یا خاموش کنید.
  • نمایش امکان ارسال استوری را کنترل کنید.
  • دستیار Gemini را در صورت نیاز فعال کنید، کلید API و مدل را وارد کنید، پراکسی اختیاری را تنظیم کنید، اتصال را آزمایش و سپس تنظیمات را ذخیره کنید.

خاموش کردن یک قابلیت، دسترسی به ایجاد محتوای جدید را محدود می‌کند و به‌تنهایی گروه‌ها، کانال‌ها یا استوری‌های قبلی را حذف نمی‌کند. کلید Gemini را محرمانه نگه دارید؛ هرگز آن را در کد مرورگر، README یا مخزن عمومی قرار ندهید. درخواست دستیار هنگام استفاده به سرویس Gemini یا پراکسی پیکربندی‌شده فرستاده می‌شود.

برند و هویت پیام‌رسان

در تب برند، نام برنامه، شعار، پیام خوش‌آمدگویی و URL لوگوی کامل و نماد را تنظیم کنید. پیش‌نمایش زنده را بررسی و سپس تغییرات را ذخیره کنید. فقط URLهای امن و قابل‌دسترسی برای کاربران را وارد کنید.

توکن‌های API

برای ربات، کلاینت یا ابزار اتوماسیون یک نام کاربرد و مدت اعتبار انتخاب و توکن بسازید. مقدار کامل فقط یک بار نمایش داده می‌شود و نسخهٔ ذخیره‌شده در پایگاه‌داده هش‌شده است. توکن را مثل گذرواژهٔ مدیر نگه دارید، در مخزن یا گزارش‌ها نگذارید و هنگام افشا فوراً باطل کنید.

فهرست توکن‌ها پیشوند، زمان ساخت، آخرین استفاده و انقضا را نشان می‌دهد. مرجع REST API مسیرها و روش استفاده را توضیح می‌دهد.

گزارش‌های تخلف

گزارش‌ها را با فیلتر «همه»، «در انتظار بررسی» یا «رسیدگی‌شده» مرتب کنید و برای دریافت دوباره فهرست، دکمه به‌روزرسانی را بزنید. هر گزارش نام گزارش‌دهنده، کاربر گزارش‌شده، علت و متن پیام را نشان می‌دهد.

برای گزارش در انتظار بررسی می‌توانید حساب را دائمی یا موقت مسدود کنید، پیام گزارش‌شده را حذف کنید یا گزارش را رد کنید. پیش از انتخاب، متن و زمینه گزارش را بررسی کنید؛ رد گزارش، حذف پیام و مسدود کردن حساب پیامدهای متفاوت دارند.

مدیریت کاربران

با نام نمایشی، نام کاربری یا شماره تلفن فهرست را جستجو کنید. کارت هر حساب نقش، شماره ثبت‌شده، وضعیت 2FA و وضعیت مسدودیت را نمایش می‌دهد.

  • مسدود کردن یا رفع انسداد حساب؛
  • تعیین مدت مسدودیت موقت؛
  • بازنشانی گذرواژه؛
  • خاموش کردن 2FA در صورت نیاز به بازیابی حساب؛
  • ارتقای کاربر به مدیر یا تنزل نقش مدیر.

حساب مدیر جاری از همان ردیف قابل تغییر نیست. نقش یا گذرواژه را فقط پس از بررسی شناسه حساب تغییر دهید و اطلاعات دسترسی تازه را از راه امن به صاحب حساب برسانید.

گروه‌ها و کانال‌ها

نام گروه یا کانال را جستجو کنید. با «قفل کردن» ارسال پیام در آن گفتگو را از سمت مدیریت محدود می‌کنید؛ گزینه «بازگشایی ارسال» محدودیت را برمی‌دارد. قفل گفتگو معادل حذف آن نیست.

«حذف اجباری» گفتگو را از سامانه پاک می‌کند و ممکن است بازگردانی آن ممکن نباشد. قبل از اقدام، نام گفتگو را بررسی و اگر داده لازم است از پایگاه‌داده نسخه پشتیبان تهیه کنید.

پایگاه‌داده و پاک‌سازی اضطراری

بخش پایگاه‌داده برای مرور مجموعه‌های ذخیره‌شده و عملیات خروجی/بازیابی JSON در حالت محلی است. قبل از بازیابی، پاک‌سازی یا تغییر عمده، backup مستقل بگیرید. بازیابی فایل قدیمی ممکن است داده جدیدتر را جایگزین کند.

دکمه پنیک خطرناک است: این عملیات برای پاک‌سازی اضطراری کل پایگاه‌داده است، نه ابزار نگهداری روزمره. پیش از استفاده محیط مقصد را بررسی و نسخه پشتیبان مستقل تهیه کنید.

برای MySQL یا PostgreSQL، پشتیبان‌گیری کامل را با ابزار dump همان موتور انجام دهید. فایل پشتیبان را از پوشه‌ای که وب‌سرور منتشر می‌کند دور نگه دارید.

دسترسی امن و نگهداری

  • برای حساب مدیر گذرواژه قوی و یکتا انتخاب کنید و دسترسی را فقط به مدیران مورداعتماد بدهید.
  • در استقرار عمومی پنل را پشت HTTPS قرار دهید.
  • کلیدهای API و فایل‌های پشتیبان را در مخزن عمومی یا مسیر قابل‌دسترسی وب نگذارید.
  • برای ثبت رویدادها، وضعیت سرور و backup دوره‌ای، از راهنمای مدیریت سرور استفاده کنید.

اطلاعات حریم خصوصی و محدودیت‌های رمزگذاری را در راهنمای امنیت و رفع اشکال بخوانید.
