برای گفتگوهای روزمره و مدیریت جامعه

StarGram ابزارهای گفتگو، مدیریت و نگهداری داده را در یک برنامه خودمیزبان جمع می‌کند.

◉

گفتگوی خصوصی

پیام متنی، پاسخ، ویرایش، واکنش، سنجاق، ارسال مجدد و پیام‌های ذخیره‌شده.

♧

گروه‌ها

گروه عمومی یا خصوصی بساز، مخاطبان را دعوت کن و اعضا و مدیران را مدیریت کن.

▤

کانال‌ها

برای انتشار پیام به مشترکان کانال ایجاد کن و مدیر، لینک دعوت و واکنش‌ها را تنظیم کن.

▧

رسانه و استوری

تصویر، پیام صوتی، نظرسنجی و استوری تصویری، ویدئویی یا متنی ارسال کن.

◐

تنظیمات شخصی

تم، پس‌زمینه گفتگو، اندازه متن، اعلان‌ها، حریم خصوصی و رفتار نوشتن را انتخاب کن.

⌘

مدیریت سرور

پنل مدیریت، ابزار خط فرمان انگلیسی، ثبت گزارش، پشتیبان‌گیری و به‌روزرسانی مستقیم.

▦

پایگاه داده انتخابی

PostgreSQL یا MySQL/MariaDB برای سرور، یا فایل JSON محلی برای شروع ساده.

وب‌اپ قابل نصب

در مرورگر سازگار StarGram را به صفحه اصلی یا فهرست برنامه‌ها اضافه کن.

نصب سریع

راه‌اندازی روی سرور لینوکس

اسکریپت نصب، Node.js، وابستگی‌ها، تنظیمات پایگاه داده و سرویس systemd را آماده می‌کند.

نصب‌کننده باید با دسترسی root اجرا شود. برای سرور عمومی، StarGram را پشت Nginx یا Caddy با HTTPS قرار بده. قبل از نصب، محتوای اسکریپت نصب را بررسی کن.

نصب تعاملی

sudo bash <(curl -fsSL https://raw.githubusercontent.com/arimakomi/StarGram/main/setup.sh)

در بعضی shellها، اجرای مستقیم process substitution با sudo پشتیبانی نمی‌شود. دستور قابل‌حمل‌تر:

curl -fsSL https://raw.githubusercontent.com/arimakomi/StarGram/main/setup.sh -o setup.sh
sudo bash setup.sh

نصب‌کننده پورت، نام کاربری مدیر، رمز عبور و نوع پایگاه داده را می‌پرسد. برای شروع ساده، پایگاه داده local را انتخاب کن؛ برای استقرار جدی‌تر PostgreSQL یا MySQL/MariaDB را از قبل آماده کن.

نصب غیرتعاملی با JSON محلی

sudo NONINTERACTIVE=1 PORT=3000 \
  ADMIN_USER=admin ADMIN_PASS='Use-A-Long-Unique-Password' \
  DB_TYPE=local bash setup.sh

بعد از نصب

نشانی دسترسی و نام مدیر را از خروجی نصب‌کننده بردار. اگر رمز مدیر را نصب‌کننده تصادفی ساخته، همان لحظه آن را ذخیره کن؛ رمز تولیدشده در متن ساده نگهداری نمی‌شود. سپس دامنه و HTTPS را با reverse proxy تنظیم و ورود را از مرورگر بررسی کن.

تمام مراحل نصب و استقرارتنظیم پایگاه داده
نگهداری

مدیریت و به‌روزرسانی

پس از نصب، فرمان stargram برای مشاهده وضعیت سرویس و کارهای رایج در دسترس است.

وضعیت و گزارش‌ها

sudo stargram status
sudo stargram logs
sudo stargram health

پشتیبان‌گیری

sudo stargram backup

در حالت JSON نسخه فشرده می‌سازد؛ برای SQL از ابزار dump پایگاه داده استفاده می‌کند.

به‌روزرسانی

sudo stargram update

نسخه main را از GitHub می‌گیرد و به build و راه‌اندازی مجدد سرویس می‌رسد؛ حتی اگر پوشه نصب Git checkout نباشد.

پیش از به‌روزرسانی نسخه پشتیبان بگیر. به‌روزرسانی فایل‌های کد را جایگزین می‌کند و ممکن است تغییرات محلی کد را بازنویسی کند؛ فایل‌های داده، پشتیبان‌ها، تنظیمات .env و وابستگی‌ها حفظ می‌شوند.
