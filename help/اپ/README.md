# راهنمای اپ StarGram

این پوشه برای مستندات نسخه اپ در نظر گرفته شده است. نسخه فعلی این مخزن، پیام‌رسان وب است و می‌تواند در مرورگر به شکل وب‌اپ (PWA) نصب شود؛ اپ بومی جداگانه برای Android یا iOS در این مخزن ارائه نشده است.

برای نصب نسخه وب‌اپ و رفع مشکل نمایش گزینه نصب، به [راهنمای نصب PWA](../وب/pwa.md) بروید. راهنماهای حساب، گفتگو، گروه، کانال و تنظیمات در [فهرست راهنمای وب](../وب/README.md) قرار دارند.
